## 2025-05-23 - Missing Password Complexity Enforcement
**Vulnerability:** The application lacked consistent password complexity enforcement across several key areas: `AuthService.changePassword`, `StaffService` (hotel staff creation/update), `PublicService` (guest registration), and `UserManagementService` (platform user creation/password change). While a `PasswordPolicyService` existed, it was only being utilized in a few places, leaving multiple entry points where weak passwords could be set.
**Learning:** Security controls like password policies must be applied at every point where a credential can be established or modified. Relying on front-end validation or partial back-end coverage is insufficient for "Defense in Depth".
**Prevention:** Integrate the centralized `PasswordPolicyService.assertCompliant()` check into all service methods that handle password creation or updates. Export this service from a core/shared module (e.g., `PlatformModule`) to ensure it's easily available across all functional domains (Auth, Public, Staff).
